# Primal Peptides Redesign

Redesign the existing Primal Peptides UK website as a simple, professional, elegant front end concept using the current website information and the client's newly requested changes. Keep the site concise and not content heavy. Use a clean premium dark navy, blue and teal visual direction that suits the existing brand. Preserve the recognisable Primal Peptides UK identity, elephant and DNA concept, but use a placeholder area for the improved logo if the final asset is not yet available.

The website is for research peptides. The redesign should make the website look significantly more professional while remaining straightforward and easy to navigate.

Priority requirements to feature clearly in the design:
1. Prominent wording on the homepage and relevant product areas: “For research purposes only” and “Not for human consumption”.
2. An 18+ age confirmation concept in the purchase journey. Show a clear age confirmation modal or checkout gate where the customer confirms they are 18 or over before proceeding.

Homepage direction:
• Clean header with logo, Shop, About/Research Information, Contact and Cart
• Strong but minimal hero section
• Clear research use notice near the hero
• Simple featured product/shop section using existing product information where appropriate
• Short research information section
• Professional trust/information area without making unsupported claims
• Clear contact/business information
• Elegant footer with research use wording repeated
• Strong mobile responsiveness

Design direction:
• Premium, modern, clean and elegant
• Avoid excessive text, clutter or overly futuristic effects
• Good whitespace and spacing
• Professional typography
• Refined buttons and product cards
• Consistent dark navy / blue / teal palette
• Make it realistic for a WordPress/WooCommerce designer to recreate later

Important project constraints:
• This is a design prototype/redesign concept only. Do not invent regulatory approvals, medical claims, payment processor approval, bank approval or compliance claims.
• Do not add human-use claims, dosage guidance or treatment claims.
• Do not permanently remove or invent products.
• Keep research-only positioning clear and consistent.
• The final design should be simple enough that the existing WordPress/WooCommerce website can later be rebuilt to visually match it.

Please build the full responsive homepage and representative shop/product/checkout-age-confirmation views so we can use the result as the visual reference for the WordPress redesign.
